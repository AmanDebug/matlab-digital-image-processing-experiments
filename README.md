# Digital Image Processing Lab (ECE4012)

A collection of MATLAB scripts demonstrating core digital image processing techniques. These experiments were developed as part of the B.Tech Electronics and Communication Engineering curriculum at VIT Bhopal. 

## 🔬 Experiments Covered

This repository contains MATLAB implementations for the following concepts:

1. **Color Space Manipulation:** Extracting RGB components and grayscale conversion.
2. **Spatial Filtering:** Constructing and applying 5x5 Gaussian, Average, and Median filters for noise reduction.
3. **First-Order Edge Detection:** Applying Sobel and Prewitt operators.
4. **Second-Order Edge Detection:** Utilizing positive and negative Laplacian operators.
5. **Histogram Equalization:** Global Histogram Equalization and CLAHE methods.
6. **Advanced Filtering:** Deblurring and denoising (Salt & Pepper, Gaussian, Speckle) using the Wiener filter.
7. **Discrete Cosine Transform (DCT):** Calculating coefficients and recovering RGB images using IDCT.
8. **Discrete Wavelet Transform (DWT):** RGB image decomposition and recovery using IDWT.
9. **Image Quality Metrics:** Calculating Mean Squared Error (MSE) and Peak Signal-to-Noise Ratio (PSNR) for Gaussian noise reduction.
10. **Advanced Computer Vision:** Implementing Canny edge detection and SIFT feature extraction.

## 🛠️ Tech Stack & Requirements

* **Language:** MATLAB
* **Toolboxes Required:** 
  * Image Processing Toolbox
  * Computer Vision Toolbox (for SIFT feature extraction in Experiment 10)
* **Dataset:** Images used for testing (e.g., Lena, Peppers, Mandrill) are sourced from the [USC-SIPI Image Database](https://sipi.usc.edu/database/database.php?volume=misc).
